# HappyPaws Pet Supply Co.

Starter company storefront for a USA-focused pet store.

## Important before launch
- Replace the placeholder company name, email, products, prices and business details.
- Connect a verified payment provider belonging to the actual business owner (for example Stripe or PayPal).
- Configure real shipping rates and tax rules.
- Add a secure backend/database for orders.
- Never use fabricated customer profiles, fake testimonials, fake transactions or misleading reviews. Use real customer consented testimonials only.

This version is a static front-end prototype and does **not** process real payments.
